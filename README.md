# VoidDRAM
Во время долгих игровых сессий (в PUBG, Rust, Таркове и других тяжелых играх) Windows забивает оперативную память так называемым «кэшем ожидания» (Standby List). 
Когда память забивается под 100%, Windows экстренно сбрасывает кэш, из-за чего игра **резко зависает на пол секунды** прямо посреди игры.
**VoidDRAM** незаметно висит в фоне и автоматически освобождает память в нужный момент, не нагружая процессор и не трогая нужные игре файлы.
## Как это работает?
* **Плавность в играх:** предотвращает внезапные зависания и статтеры из-за нехватки свободной памяти.
* **Умная очистка:** сбрасывает только мусор. Все текстуры и звуки вашей запущенной игры остаются в ОЗУ.
* **Таймер 1 мс:** снижает стандартную задержку системного таймера Windows (с 15.6 мс до 1 мс), делая задержки ниже, а фреймтайм ровнее.
* **0% нагрузки на CPU:** программа спит и просыпается только по сигналу системы, когда память реально на исходе.
